# 🎵 Spotify Music Analysis Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive **Spotify Music Analysis Dashboard** built using **Microsoft Power BI**.
The dashboard provides valuable insights into music trends, artist performance, track popularity, and audio features by analyzing Spotify data.

The goal of this project is to transform raw Spotify data into meaningful visual insights that help users understand **listening patterns, popular artists, genres, and song characteristics**.

---

## 🎯 Problem Statement

Spotify contains massive amounts of music data, but raw data alone does not provide actionable insights.
**The challenge** is to analyze Spotify music data and design an interactive dashboard that allows users to:

* Identify popular tracks and artists
* Analyze music trends based on popularity and audio features
* Understand listener preferences using visual analytics

---

## ✅ Business Objectives

* Analyze **top artists, tracks, and genres**
* Identify patterns in **song popularity**
* Enable **data-driven decisions** for music recommendations and trend analysis

---

## 📊 Dashboard Features

* 🎵 Top Tracks & Top Artists Analysis
* ⭐ Popularity Trends Overview
* 📈 Interactive filters & slicers for dynamic analysis
* 📉 Visual comparison across multiple dimensions

---
